The simulations need Python 3.12 with numpy, scipy, matplotlib and pytest, plus MicroscPSF-Py for software/sim/optics_v1.py. Each script rewrites its own report in docs/design/, so you can diff your run against ours. The README lists the commands.

Rerun on our machine, with Python 3.12 and the numpy, scipy and matplotlib versions pinned in software/requirements.lock, red-team gel S3 (software/redteam/s3_gen.py) came out byte for byte the same as our original run once decompressed; the .json.gz files themselves differed only in the time stamped in their gzip header. Since 2026-10-10 the generator writes that header with no time stamp, and two more runs on our machine gave byte-identical .json.gz files.
